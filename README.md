# 🕷️ Beyond the Spider-Verse - Web Concept & Study

Um site conceitual, interativo e imersivo baseado no futuro filme **Spider-Man: Beyond the Spider-Verse**. Este projeto foi construído como um desafio pessoal de desenvolvimento front-end para explorar e consolidar técnicas avançadas de animação, manipulação do DOM e estilização inspirada em histórias em quadrinhos (HQs).

---

## 🚀 O Desafio & Objetivo
O objetivo principal deste projeto é demonstrar minhas habilidades técnicas e evolução no desenvolvimento de interfaces criativas. Busquei recriar a identidade visual única da franquia: uma mistura de animação cartoon 3D com texturas e efeitos clássicos de HQs impressas (como retículas Ben-Day, linhas de ação e transições dramáticas).

---

## 🎭 Destaques do Projeto (Feature Section)
O grande ápice técnico deste site é a **Seção do Espelho (O Confronto)**:
* **Efeito Sentido Aranha:** Uma transição brusca que inverte as cores da tela (`filter: invert(1)`) simulando o perigo iminente.
* **O Reflexo do Vilão:** Uma mecânica onde Miles Morales está de costas para a tela olhando para um espelho, revelando o seu próprio reflexo distorcido (sua versão alternativa do multiverso) no painel reflexivo.
* **Animação Split-Text:** A revelação do texto dramático *"Now, Miles will defeat your demons!"* usando quebra de caracteres/palavras animadas de forma sequencial por meio de bibliotecas de animação modernas.

---

## 🛠️ Tecnologias e Conceitos Estudados
* **Framework Principal:** React + Vite (Fast Refresh e Performance)
* **Estilização:** CSS Modules / Styled-Components (Com estética Comic Book)
* **Animações Avançadas:** GSAP (GreenSock) ou Framer Motion para o *Split-Text* e transições de tela.
* **Efeitos Visuais:** Filtros CSS nativos, manipulação de perspectiva e sobreposição de camadas.

## 📦 Como rodar o projeto localmente

1. Clone o repositório:
```bash
git clone https://github.com
```

2. Entre na pasta do projeto:
```bash
cd beyond-the-spiderverse-web
```

3. Instale as dependências:
```bash
npm install
```

4. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```
